  \caption{\textbf{Tactile analogies.} Given a reference touch recorded on an object (top row,
    right) together with the surface geometry at the location it was taken from (top row, left),
    we predict the tactile signal that the sensor would measure at a new, previously untouched
    location (bottom row, right) given only the geometry there (bottom row, left). We represent a
    touch as a \emph{tactile normal video}, which records how the sensor's deformable gel bends
    over the course of a press, so the prediction is a short video rather than a single frame;
    six frames spanning the press are shown for each. The reference is the one our method
    retrieved on its own from the object's remaining touches, so the figure shows the complete
    pipeline rather than an oracle reference. The relationship between the two columns is the
    analogy our method must transfer: as the reference geometry is to the reference touch, so the
    query geometry is to the touch we synthesise. The red box marks the patch the sensor actually
    covers inside the wider geometry render our method compares.}
