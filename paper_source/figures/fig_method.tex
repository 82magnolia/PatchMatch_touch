  \caption{\textbf{Method overview.} (a) Every reference touch is stored alongside a surface
    normal map rendered at its sensor pose. We encode these normal maps with a frozen DINOv3
    encoder and pick the reference whose feature is closest to the query's
    (Sec.~\ref{sec:retrieval}). (b) We match local features between the selected reference normal
    map and the query normal map, fit an affine map to the correspondences, and warp the reference
    tactile video through it to obtain an initial transfer (Sec.~\ref{sec:coarse}). (c) A
    lightweight video network refines the initial transfer. The query normal map is concatenated
    to the input frames so the network knows the surface geometry it is predicting for, and the
    normalized timestamp of the frame is injected through feature-wise linear modulation (FiLM) so
    the network knows where in the press it is (Sec.~\ref{sec:refine}).}
