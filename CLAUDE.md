# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Installation

```bash
conda create -n pm_touch python=3.10
# Install torch first (xformers setup.py imports it at build time)
pip install --extra-index-url https://download.pytorch.org/whl/cu118 torch==2.4.1 torchvision==0.19.1+cu118
# Install xformers without build isolation (needs torch visible during build)
pip install xformers==0.0.28 --no-build-isolation
pip install -r requirements.txt
conda install nvidia::cuda-toolkit
conda install conda-forge::pycuda
```

CUDA: `transfer_all.sh` explicitly prepends `/usr/local/cuda-11.8/bin` to `PATH` to avoid ABI mismatches between the conda NVCC (12.x) and the installed driver (11.x).

## Running key scripts

**Demo (single pair):**
```bash
python demo.py --img_a data/ObjectFolder_touch/36/4_scale_50_normal.jpg \
               --img_b data/ObjectFolder_touch/36/7_scale_50_normal.jpg \
               --img_a_prime data/ObjectFolder_touch/36/4_scale_50_shadow.jpg \
               --img_b_prime data/ObjectFolder_touch/36/7_scale_50_shadow.jpg
```

**Full pipeline (run from project root):**
```bash
# 1. Sample reference contact points (FPS) for all objects
bash train_refine_scripts/sample_contact_points.sh

# 2. Sample nearby query contact points
bash train_refine_scripts/sample_query_contact_points.sh

# 3. Generate reference tactile videos (single GPU)
bash train_refine_scripts/gen_contact_ref.sh
# Or 8-GPU parallel (run each on a separate GPU):
bash train_refine_scripts/gen_contact_ref_multi/run_gpu0.sh  # ... run_gpu7.sh

# 4. Generate query tactile videos (same pattern)
bash train_refine_scripts/gen_contact_query.sh
# Or: gen_contact_query_multi/run_gpu{0..7}.sh

# 5. Build identity TSV (needed before retrieval)
python gen_identity_tsv.py

# 6. Retrieve matching touch locations
bash train_refine_scripts/retrieve_touch_all.sh

# 7. Transfer touch videos via PatchMatch
bash train_refine_scripts/transfer_all.sh
```

## Architecture overview

### Core PatchMatch engine
- **`patchmatch_single.cu`** — CUDA kernel implementing propagation + random search
- **`PatchMatchCuda_single.py`** (`PatchMatchSingle`) — Python wrapper that compiles and runs the CUDA kernel via pycuda. Accepts an optional `init_nnf` for warm-starting. The compiled `SourceModule` is cached as a class variable so it is only compiled once per process.

### Touch video transfer (`main_retrieval_transfer_accel.py`)
The main inference script. For each query contact point it:
1. Loads the top-1 retrieved reference from a `results.pkl`
2. Runs an EM loop alternating between NNF computation (PatchMatch E-step) and weighted averaging (M-step / `reconstruct_avg`)
3. Outputs the transferred video

Key flags:
- `--use_accel` — warm-starts PatchMatch with the previous frame's NNF; reduces `pm_iters` to 1/3 and search radius to 10% for subsequent frames
- `--use_keyframe` — finds the frame with max contact area, runs full EM on it, then propagates forward/backward
- `--use_downsample_em` — runs all EM iterations at 1/`downsample_res` resolution, one final high-res reconstruction; default (`em_transfer_frame_fullres`) runs all iterations at full resolution with an optional low-res seed

### Taxim optical simulation (`Taxim/OpticalSimulation/`)
Generates synthetic tactile sensor images from 3D object meshes.
- **`simOptical.py`** (`mesh_simulator`) — core simulator: `generateHeightMap` → `deformApprox` → `simulating`
- **`gen_contact_video.py`** — batch driver: iterates contact points and press depths, outputs MP4 videos and static NPZ/JPG snapshots (color, normal, height, curvature, shapeindex)
- **`pick_contact_points.py`** — interactive GUI (pyrender/pyglet) or headless FPS sampling via `--num_fps_points`
- **`pick_contact_points_from_ref.py`** — non-interactive: samples one surface point per reference point within `[r_low, r_high]` distance using trimesh dense sampling

`gen_contact_video.py` must be run with CWD = `Taxim/OpticalSimulation/` because it does `sys.path.append("..")` to import `simOptical`, which in turn imports `from Basics.RawData import RawData` (requiring `Taxim/` on the path).

### Retrieval (`retrieve_touch.py`)
Two modes via `--retrieval_mode`:
- `dinov2` — builds a DINOv2 feature database and retrieves top-K similar entries
- `tsv` — loads pre-specified query→ref mappings from a TSV file

For the full-dataset pipeline, `retrieve_touch_all.sh` uses `tsv` mode with an identity mapping (query idx = ref idx), generated by `gen_identity_tsv.py`.

### Headless rendering on servers
`gen_contact_video.py` uses `pyrender.OffscreenRenderer`. On headless servers, wrap each call with `xvfb-run -a` (see `gen_contact_ref_multi/_run.sh`). Do **not** set `PYOPENGL_PLATFORM=egl` — the EGL backend has a bytes/str bug in PyOpenGL and `eglInitialize` fails without a configured GPU display.

### Data layout
```
Taxim/data/ObjectFolder/{idx}/model.obj          # 3D meshes
Taxim/results/object_folder_touch/{idx}/picked_points_fps.ply    # reference contact points
Taxim/results/object_folder_touch_query/{idx}/picked_points_query.ply
Taxim/results/gen_contact_full/{idx}/            # reference tactile videos + statics
Taxim/results/gen_contact_full_query/{idx}/      # query tactile videos + statics
log/touch_retrieval/{idx}/results.pkl            # retrieval results
log/transfer/{idx}/                              # transferred output videos
```

### rebot-net (`rebot-net/`)
Post-processing enhancement network (ReBotNet) that takes PatchMatch-transferred tactile videos as input and outputs cleaner videos closer to the ground-truth query. Separate from the PatchMatch pipeline.

Key files:
- **`models/archs.py`** (`rebotnet`) — ConvNeXt encoder + bottleneck MLP-mixer transformer + skip-connection decoder. `forward` expects `(B, 2, 3, H, W)` (frame pair); `x[:,1,...]` is the main frame used for the residual output. The bottleneck uses `F.adaptive_avg_pool2d` to normalize token counts to 576 (24×24) regardless of input resolution, then bilinear-upsamples back to encoder spatial dims before the decoder. H and W must be divisible by 16.
- **`dataset.py`** (`TactileTransferDataset`) — builds a flat `(obj_id, pair_idx, frame_idx)` sample list; `__getitem__` returns `lq (2,3,H,W)` frame pair (t-1, t) and `gt (3,H,W)`; `iter_video_pairs` yields sequential frames for evaluation.
- **`trainer.py`** (`Trainer`) — Charbonnier loss training loop with wandb step logging and console progress; `evaluate` computes per-video MSE/PSNR/SSIM/LPIPS with optional video saving.
- **`train.py`** — main training script; saves `best.pth` (best val PSNR) and `latest.pth`.
- **`eval.py`** — test-split evaluation; prints per-object metrics and saves `metrics.pkl`.

Data split (objects sorted numerically, 1–1000):
- Train: 1–930 · Val: 931–950 · Test: 951–1000

**Training:**
```bash
python rebot-net/train.py \
    --transfer_dir log/transfer \
    --save_dir log/rebot_checkpoints \
    --model_size rebot_S \
    --epochs 100 --batch_size 4 --lr 2e-4 \
    --wandb_project tactile_enhance \
    --video_save
```

**Evaluation:**
```bash
python rebot-net/eval.py \
    --transfer_dir log/transfer \
    --checkpoint log/rebot_checkpoints/best.pth \
    --model_size rebot_S \
    --save_dir log/rebot_eval \
    --video_save
```
